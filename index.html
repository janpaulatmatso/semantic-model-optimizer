Semantic Model Optimizer

Load the model from a server. Use this when the model is not in your project, for example a thin report on Analysis Services or on a Power BI workspace. Only the definition is read; nothing is changed.

A cloud server opens a sign-in window. Reading the definition needs admin or write permission on the model.

Load a Power BI project

Drop a folder or file here, or choose Open folder.

  • Power BI project (.pbip folder) — model and report, fully supported.
  • .pbit (template) — model and report.
  • .pbix — report only; the model inside a .pbix cannot be read. Combine it with the model as .pbip or .pbit.

Rows and MB per table? Choose Sizes from Power BI Desktop while the report is open there, or load a .vpax (DAX Studio › Advanced › Export Metrics).

Rows and MB per table? Load a .vpax (DAX Studio › Advanced › Export Metrics).

Working from a Git repository? Choose Repositories and connect the local folder. The tool finds every Power BI project in it and lets you pick the reports.

Several reports on one model? Open the folder that holds them all, or add more reports after loading. Everything stays on this computer.

Web version. It reads the files in your browser and sends nothing anywhere. In Edge or Chrome, changes you make are saved in the folder you opened, with a copy of the old files in smo-backup; the browser asks first. Install it with Install as app (or the install icon in the address bar) to use it offline. Connecting to Analysis Services, a workspace or Power BI Desktop needs the desktop app.

The model is not loaded (for example because it lives on Analysis Services). You see the measures the reports define themselves and the fields they use; whether those fields exist cannot be checked. Load the model next to it as model.bim, a Power BI project or a .pbit to check everything.
