Semantic Model Optimizer

Laad een Power BI-project

Sleep een map of bestand hierheen, of kies Map openen.

  • Power BI-project (.pbip-map) — model én rapport, volledig ondersteund.
  • .pbit (sjabloon) — model én rapport.
  • .pbix — alleen het rapport; het model in een .pbix is niet leesbaar. Combineer met het model als .pbip of .pbit.

Aantal regels en MB per tabel? Laad daarna een .vpax (DAX Studio › Advanced › Export Metrics), of start de tool met node serve.js en lees de groottes rechtstreeks uit Power BI Desktop.

Meerdere rapporten op één model? Open de map waar ze samen in staan. Alles blijft op deze computer.
