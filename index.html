Semantic Model Optimizer

Load a Power BI project

Drop a folder or file here, or choose Open folder.

  • Power BI project (.pbip folder) — model and report, fully supported.
  • .pbit (template) — model and report.
  • .pbix — report only; the model inside a .pbix cannot be read. Combine it with the model as .pbip or .pbit.

Rows and MB per table? Afterwards load a .vpax (DAX Studio › Advanced › Export Metrics), or start the tool with node serve.js and read the sizes straight from Power BI Desktop.

Working from a Git repository? Start the tool with node serve.js, choose Repositories and connect the local folder. The tool finds every Power BI project in it and lets you pick the reports.

Several reports on one model? Open the folder that holds them all, or add more reports after loading. Everything stays on this computer.
